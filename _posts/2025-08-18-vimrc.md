这里提供一个理论上在多数 linux 系统下都能快速上手的 cpp 环境配置.

- 机器需要有 `vim`, `gcc`, `gdb`.
- 需要自己创建文件夹 `runtime/`, 文件 `runtime/main.in`.
- 需要自己创建并填充 `~/.vimrc`, `~/.gdbinit`, `./_vim_template.cpp`, `./_vim_run.sh`.

## vimrc

```vim
colo slate
syn on
filet plugin indent on
se nocp  mouse=a  nu rnu hls is  et sr sw=4 sts=4  udf spr
nn <C-a> ggVG
nn <C-s> :w<CR>
au BufNewFile *.cpp silent! 0r _vim_template.cpp
nn <Esc><C-n> :wa<CR>:vert ter ./_vim_run.sh %:r<CR>
nn <Esc><CR> :vs ./runtime/main.in<CR>
nn <F5> :wa<CR>:vert ter gdb ./runtime/%:r<CR>
```

## gdbinit

```gdb
set debuginfo enabled off
```

## _vim_template.cpp

```cpp
#include <bits/stdc++.h>
#define all(a) a.begin(), a.end()
using namespace std;
using ll = long long;
using pii = pair<int, int>;

int main() {
    cin.tie(nullptr)->sync_with_stdio(false);

    return 0;
}
```

## _vim.run.sh

```bash
#!/usr/bin/env bash
set -e
ulimit -s unlimited
g++ -DDEBUG -fsanitize=address,undefined "$1.cpp" -o "./runtime/$1" -Wall -Wpedantic -Wextra -std=c++17 -g
time "./runtime/$1" < runtime/main.in | tee runtime/main.out
```
