给定一个 $n \times m$ 的 01 矩阵, 有多少面积不超过 $K$ 的全 0 矩阵?

## 限制

- $1 \le n, m \le 5 \times 10^5$.
- $1 \le n \times m \le 5 \times 10^6$.
- $1 \le K \le n \times m$.

## 思路

~~感觉这道题的官方题解感觉不够 educational 啊!~~

这道题目有[弱化版](simpler), 也就是去掉面积不超过 $K$ 的限制, 用的技巧叫悬线法.
那么回忆一下悬线法的核心, 记 $h_{i, j}$ 为 $(i, j)$ 位置向上延伸的最大距离
(撞上 1 或者边界为止), 那么从 $(i, j)$ 到 $(i + h_{i, j} - 1, j)$ 的这一段就是一条悬线.
接着处理 $l_{i, j} \, r_{i, j}$ 表示悬线左右的运动极限, 更精确的定义是:
$$
  \begin{aligned}
    l_{i, j} &= \max_{k < j} h_{i, k} < h_{i, j} \\
    r_{i, j} &= \min_{k > j} h_{i, k} \le h_{i, j} \\
  \end{aligned}
$$
注意这里一边取小于号, 一边取小于等于. 边界条件是 $h_{i, -1} = h_{i, m + 1} = -\infty$.
可以用单调栈或者递推来处理. (下面的代码索引从 $0$ 开始, `a` 是给定的矩阵)

```cpp
vector<vector<int>> H(n, vector<int>(m));
stack<int> stk;
auto L = H, R = H;
for (int i = 0; i < n; i++) {
  for (int j = 0; j < m; j++) {
    if (a[i][j] == '#') {
      H[i][j] = 0;
    } else {
      H[i][j] = i == 0 ? 1 : H[i - 1][j] + 1;
    }
  }
  for (int j = 0; j < m; j++) {
    while (!stk.empty() && H[i][j] <= H[i][stk.top()]) stk.pop();
    L[i][j] = stk.empty() ? -1 : stk.top();
    stk.push(j);
  }
  while (!stk.empty()) stk.pop();
  for (int j = m - 1; j >= 0; j--) {
    while (!stk.empty() && H[i][j] < H[i][stk.top()]) stk.pop();
    R[i][j] = stk.empty() ? m : stk.top();
    stk.push(j);
  }
  while (!stk.empty()) stk.pop();
}
```

预处理完了, $(i, j)$ 位置对弱化版题目的贡献是 $(j - l_{i, j}) \times (r_{i, j} - j) \times
h_{i, j}$. 也就是从 $(i, j)$ 出发任选左右上边界.

现在加上面积限制, 我们先分析 $(j - l_{i, j}) \times (r_{i, j} - j)$ 这两项, 令 $x = j - l_{i, j},
\, y = r_{i, j} - j$ 并且 $x \le y$. 虽然左右边界有两维, 但是我们只关心它们的宽度, 考虑数列
$1, 2, 3, \ldots, x - 2, x - 1, x, x, \ldots, x, x, x - 1, x - 2, \ldots, 3, 2, 1, 0, 0, 0, \ldots$,
这个数列的第 $w$ 项就是横向宽度为 $w$ 时左右边界可能选取的数量. 弱化版的贡献就是对于每个 $h' \in
[1, h_{i, j}]$ 把这整段数列都累加上. 这时可以考虑矩阵

$$
  \begin{bmatrix}
    1      & 2      & \cdots & x - 1  & x      & \cdots & x      & x - 1  & \cdots & 1      \\
    1      & 2      & \cdots & x - 1  & x      & \cdots & x      & x - 1  & \cdots & 1      \\
    1      & 2      & \cdots & x - 1  & x      & \cdots & x      & x - 1  & \cdots & 1      \\
    \vdots & \vdots & \ddots & \vdots & \vdots & \ddots & \vdots & \vdots & \ddots & \vdots \\
    1      & 2      & \cdots & x - 1  & x      & \cdots & x      & x - 1  & \cdots & 1
  \end{bmatrix}
$$

这个矩阵的 $h$ 行 $w$ 列处就是从位置 $(i, j)$ 出发选择左右上边界, 得到 $h \times w$ 矩形的方案数.
虽然这个矩阵很大, 我们横向二阶差分后纵向一阶差分, 只需要修改 $4$ 个点就可以记录下来.
对于所有 $(i, j)$ 在一个全局的 buffer 上累加这个矩阵, 最后只对其中 $h \times w \le K$ 的位置求和,
就得到答案了.

```cpp
vector<vector<ll>> buf(n, vector<ll>(m + 2));
for (int i = 0; i < n; i++) {
  for (int j = 0; j < m; j++) {
    if (a[i][j] == '#') continue;
    int x = j - L[i][j], y = R[i][j] - j, h = H[i][j];
    if (x > y) swap(x, y);
    buf[h - 1][0]++, buf[h - 1][x]--;
    buf[h - 1][y]--, buf[h - 1][x + y]++;
  }
}
ll ans = 0;
for (int i = n - 1; i >= 0; i--) {
  for (int j = 1; j < m; j++) buf[i][j] += buf[i][j - 1];
  for (int j = 1; j < m; j++) buf[i][j] += buf[i][j - 1];
  for (int j = 0; j < m; j++) {
    if (i != n - 1) buf[i][j] += buf[i + 1][j];
    if ((i + 1) * (j + 1) <= K) {
      ans += buf[i][j];
    }
  }
}
cout << ans << "\n";
```
