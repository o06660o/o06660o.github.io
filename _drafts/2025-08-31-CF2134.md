## 思路

由于每次丢出的球只会向右移动, 我们考虑从右往左确定每一个盒子里的元素.

虽然 $a_n$ 无法直接确定, 但是 $a_{n - 1}$ 丢一次球可以唯一确定, 交换之后再丢一次球,
那么最后两个元素都知道了.

是否还有位置无法依赖后面状态唯一确定呢? 当然还是有的, 考虑记 $f_i$ 为从位置 $i$
丢出球能够跳跃的次数. 那么只要 $f_{i + 1} = f{i + 2}$, 位置 $i$ 就无法通过丢出球来确定.
这时可以联想上一段确定 $a_n$ 的方式. 如果 $a_i$ 无法用一次询问确定, 那么 $a_{i - 1}$
一定可以, 并且它们两个只需要 $3$ 次询问即可完全确定.

具体的实现方式其实不需要和官方题解一样扫描两遍, 我们记录所有交换的位置, 把最终态 $a'$
逆序换回来就是初始态 $a$ 了.

最后考虑一下边界条件. 一个是 $f_n = f_{n + 1} = 0$, 另一个是 $a_0$ 只能和后面交换.
(如果 $a_0$ 无法一次丢球确定, 那么 $a_1$ 一定可以一次丢球确定, 交换过去有解)

## 代码

```cpp
#include <bits/stdc++.h>
#define ALL(a) (a).begin(), (a).end()
using namespace std;

void solve() {
  int n;
  cin >> n;
  vector<int> swapp;
  swapp.reserve((n + 1) / 2);
  auto query1 = [&](int x) {
    swapp.push_back(x);
    cout << "swap " << x + 1 << endl;
  };
  auto query2 = [](int x) {
    cout << "throw " << x + 1 << endl;
    int resp;
    cin >> resp;
    return resp;
  };

  vector<int> a(n, -1), f(n + 2);
  for (int i = n - 1; i >= 0; i--) {
    if (f[i + 1] == f[i + 2]) {
      if (i == 0) {
        query1(0);
        swap(a[0], a[1]);
        a[1] = query2(1) == f[2] + 1 ? 1 : 2;
      } else {
        f[i] = f[i + 1] + 1;
        f[i - 1] = query2(i - 1);
        a[i - 1] = f[i - 1] == f[i] + 1 ? 1 : 2;
        query1(i - 1);
        swap(a[i - 1], a[i]);
        f[i - 1] = query2(i - 1);
        a[i - 1] = f[i - 1] == f[i] + 1 ? 1 : 2;
        i--;
      }
    } else {
      f[i] = query2(i);
      a[i] = f[i] == f[i + 1] + 1 ? 1 : 2;
    }
  }

  reverse(ALL(swapp));
  for (auto x : swapp) swap(a[x], a[x + 1]);
  cout << "!";
  for (int i = 0; i < n; i++) {
    assert(a[i] != -1);
    cout << " " << a[i];
  }
  cout << endl;
}

int main() {
  cin.tie(nullptr)->sync_with_stdio(false);
  int tt = 1;
  cin >> tt;
  while (tt--) solve();
  return 0;
}
```
